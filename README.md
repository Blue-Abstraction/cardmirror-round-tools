# CardMirror Round Tools Plugin

Round Tools is a plugin by Evan Xiang for Anthony Truf's [CardMirror](https://github.com/ant981228/cardmirror).

This is plugin is a collection of small features that debaters can use in-round to make certain tasks easier and more efficient! You can check out what each feature does below. 

Email me at `blueabstractionoop@gmail.com` for any comments, issues, or more features you want to see added!

## Current Features
### Round Context
- A short form that debaters fill out before a round starts for some other features to work.
- Asks questions about the tournament and round, the side they're on, the schools and team codes, and the judge(s).
### Smart Doc
- An improved version for CardMirror's `New Speech Doc` command using Round Context.
- Select a speech (1AC, 1NC, 2AC, etc.) and based on the info in Round Context, Smart Doc will create a speech doc with consistent file naming and headers so debaters don't have to type the same information multiple times.
### Round Report Creator
- Assign documents to speeches with buttons.
- Pressing `Round Report` will pull up a form for the debater to fill out information about the round.
- If Round Context is filled, then that info is automatically transferred. The debater will always need to fill out the affirmative name and 1NC and 2NR positions.
- This feature will automatically create a round report based on the information and the documents selected.
